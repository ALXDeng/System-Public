# Caveats register

Everything we know to be noisy, unclear or possibly inaccurate. The project is a hackathon proof of concept, so these
do **not** block using the material (see "Hackathon stance" in `AGENTS.md`). They are recorded so we know what we are
standing on and can answer a judge's question. Add to this list whenever something looks off. Append only.

Severity: `high` = could make a headline claim wrong; `medium` = affects counts or labels; `low` = cosmetic or edge case.
